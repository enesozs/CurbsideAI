# Curbside web app

Static React + MapLibre front end for Curbside AI. Build the data first (`uv run curbside basemap`, `uv run curbside build-web`), then run `npm install && npm run dev`. Tests: `npm test` (Playwright, uses the local Chrome).

Architecture, artifact formats and design decisions are in [`../docs/web.md`](../docs/web.md).
